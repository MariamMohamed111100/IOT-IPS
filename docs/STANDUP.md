# Daily standup (15 minutes, same time every day)

Each person, max 90 seconds: **1) done yesterday, 2) doing today, 3) blocked by.**
Person 1 then spends the remaining time on blockers only. Anything longer than 2 minutes goes to a side meeting.

Person 1 records daily in the `#standup` thread: blockers (with owner and time needed),
integration risks, and whether the Day-N milestone is on track (see README timeline).

Red flags to escalate immediately: a module not publishing to MQTT by end of Day 3;
anything blocking another person for more than half a day; `main` broken for more than 1 hour.
